Privacy Policy / プライバシーポリシー

最終更新日: 2026年3月20日

概要

QuickTodo は、タスク管理を補助する Chrome 拡張機能です。本ポリシーでは、拡張機能がどのようなデータにアクセスし、どのように取り扱うかを説明します。

✓

QuickTodo は、いかなる個人データも収集・送信・共有しません。

収集するデータ

QuickTodo は以下のデータを一切収集しません。

  • タスクのデータはすべて、ブラウザの chrome.storage.local にのみ保存されます。
  • 外部サーバーへのデータ送信は行いません。
  • アクセス解析・トラッキング・テレメトリは一切使用しません。
  • アカウント登録やサインインは不要です。
  • 訪問したページのコンテンツを読み取ることはありません。

権限の説明

権限 使用目的
storage タスクをデバイス上にローカル保存するために使用します。
commands キーボードショートカット（Alt+Shift+D）を登録するために使用します。
host_permissions
（<all_urls>）		 すべてのページ下部にタスクバーを表示するため、コンテンツスクリプトを注入します。訪問先のページのコンテンツを読み取ったり、送信したりすることはありません。

データの保存

タスクは chrome.storage.local に保存されます。これはブラウザ内のローカルストレージであり、外部に送信されることはありません。Chrome Sync やクラウドサービスとの同期も行いません。

拡張機能をアンインストールすると、保存されたすべてのデータは完全に削除されます。

第三者サービス

QuickTodo は、いかなる第三者のサービス・API・ライブラリも使用していません。

ポリシーの変更

本ポリシーを改訂した場合は、このページに最新版を掲載し、更新日を変更します。

お問い合わせ

本プライバシーポリシーに関するご質問は、Chrome Web Store の拡張機能サポートページからお問い合わせください。

Overview

QuickTodo is a Chrome extension that helps you manage tasks. This policy explains what data the extension accesses and how it is handled.

✓

QuickTodo does not collect, transmit, or share any personal data.

Data We Collect

QuickTodo does not collect any of the following:

  • All task data is stored exclusively in your browser using chrome.storage.local.
  • No data is ever sent to any external server.
  • No analytics, tracking, or telemetry of any kind is used.
  • No account or sign-in is required.
  • The extension does not read the content of any pages you visit.

Permissions Explained

Permission Purpose
storage Used to save your tasks locally on your device.
commands Used to register the keyboard shortcut (Alt+Shift+D) for completing the top task.
host_permissions
(<all_urls>)		 Required to inject a content script that displays the task bar at the bottom of every webpage. The extension does not read, collect, or transmit any content from visited pages.

Data Storage

Tasks are stored in chrome.storage.local, which is a browser-local storage mechanism. Data is never synced to Chrome Sync or any cloud service.

Uninstalling the extension will permanently delete all stored task data.

Third Parties

QuickTodo does not use any third-party services, APIs, or libraries.

Changes to This Policy

If this policy is updated, the new version will be published on this page with an updated date.
